# Privacy Policy

The current version of this policy lives at [santiagoalonso.com/markflow/privacy](https://santiagoalonso.com/markflow/privacy). This copy matches it.

**Markflow** is a Markdown reader and editor for iPhone, published by Santiago Alonso.

## Data collection

Markflow does not collect, store, transmit, or share personal data. It has no accounts, analytics, advertising, or cloud sync. Documents render locally in a sandboxed view that can't send anything out. The only time Markflow connects to the internet is to display an image a document links to on the web (for example, a badge in a README); like any web image, the site hosting it can see that request.

## Your files

Markflow only opens Markdown files you choose from Files, Mail, Safari, the share sheet, or another app. Files open read-only, and edits stay in memory until you choose Save, which writes back to that file, Save as New File, Share, or Export as PDF.

Images you insert come from the system photo picker, which gives Markflow only the photos you select. They are saved next to the Markdown file. Markflow does not access your contacts, location, microphone, or camera.

## Children

Markflow is suitable for all ages and does not knowingly collect data from anyone, including children under 13.
